# OpenAPI source

`openapi.json` is the Stirling PDF Processing API document from:

<https://registry.scalar.com/@stirlingpdf/apis/stirling-pdf-processing-api/>

- Title: Stirling PDF - Processing API
- Version at vendoring time: 1.0.1
- OpenAPI: 3.0.3
- Operations: 76
- Retrieved: 2026-11-17

Regenerate the low-level client and models with:

```bash
go generate ./api
```

`hack/update-spec.sh` fetches the document again and regenerates both the API
code and the CLI operation registry.

`types.gen.go` and `client.gen.go` are generated by
[`oapi-codegen`](https://github.com/oapi-codegen/oapi-codegen) v2.5.1. Do not
edit them by hand.
